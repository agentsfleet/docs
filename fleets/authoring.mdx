## What this does

The first message creates your fleet, opens its chat, and starts the work you describe. Follow-up messages reach the same fleet.

## Before you begin

Sign in and select a workspace with a usable model and enough balance for a reply. The workspace owner's [model settings](/fleets/model-providers) determine which models you can choose.

The New fleet picker shows the usable default by name. If your picker reads **Workspace model**, sending uses the workspace owner's default. The platform default applies when the owner uses the platform's model.

## Steps

1. Open **New fleet** in the workspace sidebar.
2. Check the model, or open the picker to choose another available model.
3. Send the first task. Include the goal, inputs, and constraints the fleet should follow.

Open a suggestion to fill the composer with editable text. You can also write your own request.

### Give standing guidance

Ask the fleet to remember a rule it should follow in later work. For example, send “Remember to link the evidence when you summarize a deployment.” The fleet can pin that guidance to its memory.

Ask in chat when you want the fleet to add a schedule, register a trigger, or start a durable task. The fleet asks for access when a tool needs a secret or integration. Review the card in chat and choose **Approve** or **Deny**.

### Start from the terminal

Send the first message with [`agentsfleet fleet create`](/cli/agentsfleet#chat), then use `agentsfleet fleet steer` for follow-ups. [Start a fleet from the terminal](/fleets/install) walks through both commands.

## Verify it works

Find the fleet in **Your Fleets** and check the reply to your first message. **Wakes on**, **Can access**, and **Remembers** show what the fleet has set up as it works.

## Common problems

### Recover a stopped or failed reply

If a send could not be confirmed, use **Resend** on that message. The browser retries the same operation so a lost response does not create another fleet.

If you see **Choose model**, select an available model. Ask the owner to check [model settings](/fleets/model-providers) if the list has no usable choice.

For a failed turn, open its details in chat. Check what stopped the run before sending another message, which can incur another model charge.

## Remove or undo

Open **Fleet actions** and choose **Archive** to stop future work and keep its history. Choose **Delete** to remove the fleet and its history permanently.
