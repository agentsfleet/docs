## What this does

A fleet can answer when someone mentions the agentsfleet app in a subscribed Slack channel. The answer appears in the same thread. Retried Slack deliveries do not start another turn.

## Before you begin

Open **Connected apps** in the dashboard and connect Slack to the active workspace. Invite the agentsfleet Slack app to the channel. See [Connect a provider](/fleets/connectors).

Open the channel's details. Copy its identifier (ID) from **Channel ID** in the **About** tab.

## Steps

1. Start a fleet or open an existing one in the workspace that owns the Slack connection.
2. Send “Add a Slack mention trigger for channel `<CHANNEL_ID>`” in its chat. The fleet calls `trigger_add` with kind `mention` and that channel ID.
3. Confirm the channel under **Wakes on**. A fleet subscribes to one Slack channel.
4. Mention the app in that channel. Include the fleet's name when more than one fleet can answer.

   ```text
   @agentsfleet ci-responder why did the build fail?
   ```

A named mention matches the fleet name without regard to case. A colon or comma can follow the name. A fleet with approved GitHub write access answers only when you name it.

## Verify it works

Check for the reply in the Slack thread. Open the fleet's chat to see the turn, or list the turns from the terminal.

```bash
agentsfleet fleet turns <FLEET_ID> --actor 'slack:*'
```

```text
<varies>
```

Get `<FLEET_ID>` from `agentsfleet fleet list`. The actor identifies the Slack team and sender.

## Common problems

| Symptom | What to do |
|---|---|
| No fleet subscribes to the channel. | Connect Slack, then ask a fleet to add the channel's mention trigger. |
| Slack asks which fleet should answer. | Start your message with one of the fleet names listed in the notice. |
| The named fleet is archived. | Name an active fleet subscribed to the channel. |
| The fleet sees only your mention. | Paste relevant context into the message if Slack could not return the thread or the app cannot read private channel history. |

The app reads the first thread message and up to 19 later replies. It bounds thread retrieval to 1.5 seconds. An edited message or an app reply to itself does not start another turn.

## Remove or undo

Remove the Slack trigger under **Wakes on** in the fleet's sidebar. From the terminal, run `agentsfleet fleet triggers list <FLEET_ID>` to find the trigger identifier. Then use `agentsfleet fleet triggers delete <FLEET_ID> <TRIGGER_ID>`.
