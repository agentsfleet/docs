# Fleet library

## What it is

A library entry is reusable fleet setup. It holds one or more immutable revisions, and each revision is a reviewed Definition with its required secrets, tools, and network hosts.

The platform library is visible to every workspace. A workspace library entry is visible only inside its owning workspace.

## Why it exists

The library lets a workspace reuse a setup that someone already reviewed. A fleet created from an entry keeps the exact revision it was saved from.

## How it behaves

Entries come only from reviewed chat drafts. Saving a fleet never publishes it, and publishing never creates a fleet.

The dashboard has two tabs: **All** includes published platform setups and this workspace's setups; **This workspace** shows only this workspace's setups. An empty library means no published setups are available in that view. Create a setup in chat, review it, then publish it.

The library accepts reviewed Definitions. Older Markdown bundle entries were removed during the Definition rollout and do not appear. To reuse older instructions, paste them into a new setup chat and publish the reviewed result.

Each new fleet starts from one pinned revision. A later revision of the entry does not change fleets saved from an earlier one. To move a fleet forward, improve it in a private chat and apply the reviewed change.

`agentsfleet library` lists the gallery this workspace can use, which holds both tiers. `TIER` reads `platform` for an entry every workspace sees and `tenant` for one this workspace owns.

```bash
agentsfleet library
```

```text
NAME        LIBRARY     TIER        REVISION    AGO
<varies>
Start from a revision: agentsfleet chat --library <library_id> --revision <revision_id>
```

`REVISION` is the entry's latest revision. [Install a fleet](/fleets/install) shows how to save a fleet from it.

A page with no entries reads `No published Fleet libraries in this page.` and shows how to publish one.

## Publish a workspace entry

You publish from a reviewed draft. Publishing does not close the draft, so you can keep editing it.

In the dashboard, review the draft and choose **Publish to Library**. Then choose **Publish new entry**, or **Publish next revision** for an entry you already own.

In the terminal, publish a reviewed draft with a label. `<LABEL>` is the display name, 1 to 100 characters. `<DRAFT_ID>` and `<DIGEST>` come from the draft's review.

```bash
agentsfleet chat <DRAFT_ID> --no-input --publish <LABEL> --review-digest <DIGEST>
```

```text
<varies>
✓ Published Library revision <REVISION_ID>
```

Inside an interactive chat, `/publish <LABEL>` does the same after a `/review`.

To add a revision to an entry this workspace owns, add `--publish-to <LIBRARY_ID> --library-etag <ETAG>`. `<ETAG>` is the entry's `etag` field from `agentsfleet --json library list`. A stale tag is refused, so the revision always follows the version you inspected.

Publishing needs the `library:write` scope.

| Option | Effect | Default | Unit or range |
|---|---|---|---|
| `--publish <LABEL>` | Publishes the reviewed draft as a new entry. | None | Text, 1 to 100 characters |
| `--publish-to <LIBRARY_ID>` | Appends a revision to this owned entry instead. Needs `--publish` and `--library-etag`. | None | Library identifier |
| `--library-etag <ETAG>` | The entry tag you inspected. | None | Entity tag |
| `--review-digest <DIGEST>` | The digest of the review you inspected. | None; required | Digest text |

## List and remove workspace entries

`agentsfleet library list` lists only the entries this workspace owns. It never shows a platform entry.

```bash
agentsfleet library list
```

```text
NAME        LIBRARY     TIER        REVISION    AGO
<varies>
```

`agentsfleet library delete` takes one identifier from the `LIBRARY` column.

<Warning>
  Removal is permanent. The entry and its revision history leave the gallery, and nothing restores them.
</Warning>

```bash
agentsfleet library delete <LIBRARY_ID>
```

```text
✓ <varies> is no longer in this workspace's Fleet library. Fleets already installed from it keep running.
Publish reviewed chat setup with: agentsfleet chat --help
```

Fleets saved from the entry are untouched. Each keeps the revision it was saved from.

You can remove only an entry this workspace owns. A platform entry, another workspace's entry, or an entry already removed answers `404` with `UZ-AUTHOR-001`. All three answer the same way, so the reply never tells you whether an entry exists elsewhere.

Removal needs the `library:write` scope.

The dashboard lists the same entries at **Fleet library** in the workspace sidebar. Choose **Inspect** to read a revision, **Older revisions** for its history, or **Start chat from this revision** to open a private draft from it.

## Platform entries

Platform entries come from a reviewed draft too. An operator whose session carries the `platform-library:write` scope stages the draft, and the entry starts hidden.

1. In a workspace chat, review the draft and choose **Stage platform entry**.
2. Open **Fleet library** under Platform.
3. Edit the entry's name, description, and the reason for each credential it needs.
4. Choose **Publish**. Only published entries appear in workspace galleries.

**Withdraw** hides a published entry again. Only a withdrawn entry can be deleted. Existing fleets keep their pinned setup revision either way.

The dashboard protects edits with the version the form loaded. If another operator saves first, your stale edit is refused. Refresh the row, review the newer values, and apply your change again.

## Limits

A Definition's description allows 32,768 characters, and so do its instructions. The first instructions a chat model writes allow 12,288 characters. The whole Definition allows 448 KiB of JSON.

A Definition declares at most 128 tools, 64 secrets, and 64 network hosts. A tool name allows 128 characters, a secret name 128, and a network host 255.

Library lists return 100 entries per page at most. Use `--starting-after <CURSOR>` with the cursor the previous page prints.

Removing a fleet does not remove its library entry. Remove the entry itself with `agentsfleet library delete <LIBRARY_ID>`.
