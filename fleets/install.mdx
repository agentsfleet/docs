# Install a fleet

## What this does

This creates a fleet from one library entry. Installation is the only creation step; there is no separate start command.

## Before you begin

Sign in and select a workspace. Save every secret required by the library entry.

## Steps

1. Browse the workspace gallery.

   ```bash
   agentsfleet library
   ```

   ```text
   LIBRARY                        NAME                            TIER        SECRETS
   github-pr-reviewer             GitHub Pull Request reviewer    platform    github
   <varies>
   ```

   The gallery holds both tiers. `TIER` reads `platform` for an entry every
   workspace sees and `tenant` for one this workspace owns.

   An entry you need but cannot see is onboarded with `agentsfleet library add`.

2. Install one library entry.

   ```bash
   agentsfleet install --library github-pr-reviewer
   ```

   ```text
     Secrets: github
     Tools: http_request
     Network hosts: api.github.com
   ✓ github-pr-reviewer is live.
     Fleet ID: <varies>
     Webhook URLs (register on the upstream provider):
       github: <varies>
   ```

   The requirement lines come first, so you see what the fleet was granted
   before you see that it is live.

3. Register each printed webhook URL with its provider.

   For GitHub, open **Repository settings → Webhooks → Add webhook**. Use the matching workspace webhook secret.

## Verify it works

```bash
agentsfleet status
```

```text
Fleets
Name: github-pr-reviewer
Status: active
Events: <varies>
Budget: <varies>
Waiting: 0
```

`Waiting` counts the approvals this fleet is parked on. A count above zero also
prints the command that lists them.

## Common problems

`UZ-BUNDLE-003` means the workspace lacks a required secret. Create each named secret and run the install command again.

`UZ-AGT-006` means the fleet name already exists. Pass `--name <UNIQUE_NAME>` to install the same bundle again under a free name.

To reuse the taken name instead, run `agentsfleet kill <FLEET_ID>` and then `agentsfleet delete <FLEET_ID>`. Deletion releases the name.

After any failed install, run `agentsfleet list` before retrying. Retry only when the fleet is absent.

## Remove or undo

Deleting a fleet removes its events, telemetry, sessions, grants, keys, and memory. This loss cannot be undone.

`<FLEET_ID>` comes from `agentsfleet list`. Kill the fleet before deleting it.

```bash
agentsfleet kill <FLEET_ID>
```

```text
✓ <varies> killed.
```

```bash
agentsfleet delete <FLEET_ID>
```

```text
✓ <varies> deleted.
```
