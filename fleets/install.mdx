## What this does

Send the fleet's first task from the terminal and use the returned identifier to follow up.

## Before you begin

[Install the command-line interface (CLI)](/cli/install), run `agentsfleet login`, and select a workspace with an available model and balance.

## Steps

1. Start the fleet by sending its first message.

   ```bash
   agentsfleet fleet create "Summarize the nightly health report" --name nightly-health
   ```

   ```text
   ✓ Started fleet nightly-health (<FLEET_ID>). First turn <TURN_ID>: <varies>.
   Talk to it with: agentsfleet fleet steer <FLEET_ID>
   ```

   The command returns after the daemon accepts the message. The fleet's reply can still be running.

2. Open its interactive chat or send a follow-up with the fleet name.

   ```bash
   agentsfleet fleet steer @nightly-health "Keep the summary to three lines"
   ```

   ```text
   <varies>
   ```

   Omit the message to open interactive chat in a terminal.

## Verify it works

Read the fleet's recent turns using the identifier from the create response.

```bash
agentsfleet fleet turns <FLEET_ID>
```

```text
<varies>
```

Each accepted message has its own turn. Check the turn's status and reply before repeating a request.

## Common problems

If the name already exists, choose an unused name. When the workspace default model is unavailable, choose a usable runtime reference with [`--model`](/cli/agentsfleet#chat).

## Remove or undo

Use `agentsfleet fleet archive <FLEET_ID>` to keep the history and stop future work. See [removing a fleet](/fleets/running#remove-or-undo) if you want to delete its history too.
