# Quickstart

## What you will build

You will create a GitHub pull request reviewer fleet from a setup file. The fleet will receive pull request events and post review comments.

## Before you begin

If you need access, [join the waitlist](https://accounts.agentsfleet.net/waitlist). The website’s **Dashboard** links currently open this waitlist.

Open the [dashboard](https://app.agentsfleet.net) to manage your workspace. For your profile and sign-in security, choose **Manage account** in the account menu. You can also open [account settings](https://app.agentsfleet.net/settings/account) directly.

You need Bun 1.4 or later. You also need an `agentsfleet` account and a GitHub repository that you can manage.

Create a GitHub token that can read the repository and post comments. Keep the token ready for step 4.

## Steps

1. Install the `agentsfleet` command-line interface.

   ```bash
   bun install --global @agentsfleet/cli
   ```

   ```text
   installed @agentsfleet/cli with binaries:
    - agentsfleet
   ```

2. Check the installed version.

   ```bash
   agentsfleet --version
   ```

   ```text
   <varies>
   ```

3. Sign in through your browser.

   ```bash
   agentsfleet login
   ```

   ```text
   Login session
   session_id: <varies>
   login_url: <varies>
   browser: opened
   login complete
   ```

   Approve the request in your browser. Enter the six-digit code in your terminal when prompted.

4. Save the GitHub secret in your active workspace.

   ```bash
   agentsfleet secret create github --data='{"token":"<GITHUB_TOKEN>","webhook_secret":"<GITHUB_WEBHOOK_SECRET>"}'
   ```

   ```text
   ✓ Secret 'github' stored in vault.
   ```

   GitHub gives you `<GITHUB_TOKEN>` after you create the repository token.

   Create `<GITHUB_WEBHOOK_SECRET>` as a random value with at least 32 characters. Enter the same value in GitHub during step 9.

   The client sends both values to your workspace vault. The client does not print the values again.

5. Write the fleet's Definition to `pr-reviewer.json`.

   ```json
   {
     "schema_version": 1,
     "skill": {
       "name": "pr-reviewer",
       "description": "Reviews GitHub pull requests and posts review comments.",
       "version": "0.1.0"
     },
     "instructions_md": "Read `repo` and `number` from the event.\nFetch the pull request diff from https://api.github.com/repos/{repo}/pulls/{number} with http_request and ${secrets.github.token}.\nPost one review with event COMMENT that lists correctness, security, and test gaps.\nNever approve, merge, or close a pull request.",
     "config": {
       "name": "pr-reviewer",
       "x-agentsfleet": {
         "triggers": [{"type": "webhook", "source": "github", "events": ["pull_request"]}],
         "tools": ["http_request"],
         "credentials": ["github"],
         "network": {"allow": ["api.github.com"]},
         "budget": {"daily_nanos": "2000000000"}
       }
     }
   }
   ```

   `daily_nanos` caps spending at 2 dollars a day. [Fleet budgets](/billing/budgets) explains the unit.

6. Open a private draft from the file and review it.

   `<MODEL_REF>` names an authoring model your workspace owner enabled. [Author a fleet](/fleets/authoring) shows where it comes from.

   ```bash
   agentsfleet chat --definition pr-reviewer.json --model <MODEL_REF> --no-input --review --name pr-reviewer
   ```

   ```text
   ✓ Draft <DRAFT_ID> created
   Instance: pr-reviewer
   Runtime model: <varies>
   <varies>
   Review digest: <DIGEST>
   ```

   The review prints the setup and every secret, tool, and host it needs. Check them before you save.

7. Save the fleet with the digest from the review.

   ```bash
   agentsfleet chat <DRAFT_ID> --no-input --save --name pr-reviewer --review-digest <DIGEST>
   ```

   ```text
   <varies>
   ✓ Fleet pr-reviewer: active
   ```

   A fleet that reads `installing` is waiting on a setup check, such as an integration grant to approve. The lines after it name each check and its next step.

8. Read the fleet's webhook URL.

   `<FLEET_ID>` comes from `agentsfleet list`.

   ```bash
   agentsfleet --json fleet show <FLEET_ID>
   ```

   ```text
   <varies>
   ```

   The `webhook_urls` entry with `source` set to `github` holds the URL.

9. Add the webhook in GitHub.

   Open **Repository settings → Webhooks → Add webhook**. Use the webhook URL from step 8 as the payload URL.

   Choose `application/json` as the content type. Use the same webhook secret from step 4.

   Select **Pull requests** as the event. GitHub now sends pull request events to your fleet.

10. Open a pull request in the repository.

    GitHub sends the event after you open the pull request. The fleet then posts a review comment.

## Verify it works

`<FLEET_ID>` comes from `agentsfleet list`.

```bash
agentsfleet logs <FLEET_ID>
```

```text
Event Stream
  <varies>  webhook:github  <varies>
```

The activity stream should show a GitHub event. Check the pull request for the fleet's review comment.

## What you learned

You installed the client, signed in, and saved a secret. You reviewed a fleet's setup, saved the fleet, and connected GitHub to it.
