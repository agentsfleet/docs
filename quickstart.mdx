## What you will build

Create a fleet that turns team updates into three short bullets. It works with text you paste into chat and needs no external app connection.

## Before you begin

You need hosted access and a workspace with an available model and balance. If you need access, [join the waitlist](https://accounts.agentsfleet.net/waitlist).

## Steps

1. [Open the dashboard](https://app.agentsfleet.net), sign in, and select a workspace.
2. Choose **New fleet**. Check the model beside the message field and switch it if you prefer another available model.
3. Send your first message.

   ```text
   Summarize this update in three bullets: progress, blockers, and next actions.
   Use only the text I send. Flag missing information rather than guessing.

   The signup page is ready for review.
   The welcome email still needs copy from Maya.
   Tomorrow, review signup and finish the email.
   ```

   Sending creates the fleet and starts its first turn. Its chat opens as soon as the fleet exists.

## Verify it works

Check that the reply separates progress, blockers, and next actions. Send a follow-up asking for a shorter version. You can return to the same fleet from the sidebar.

If no model is available, ask the workspace owner to check [model settings](/fleets/model-providers). If a message fails, follow the next action shown in [the fleet's chat](/fleets/running).

## What you learned

You created a fleet by sending a message and refined its answer in the same chat.
