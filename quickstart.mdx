## What you will build

Create a fleet that turns team updates into three short bullets.
Use text you paste into chat; this task needs no external app connection.

## Before you begin

You need hosted access and a workspace with an available model and balance.
If you need access, [join the waitlist](https://accounts.agentsfleet.net/waitlist).

Setup chat and fleet replies are charged to the workspace owner's balance.
Review the proposed spending limit before saving.

## Steps

1. [Open the dashboard](https://app.agentsfleet.net) and sign in. Select the workspace where the fleet belongs.
2. Choose **New fleet**. Check the selected model, then send this request:

   ```text
   Create a fleet called team-updates.
   Summarize each message into three bullets: progress, blockers, and next actions.
   Use only the text I send. Do not add tools, connections, schedules, or webhooks.
   Flag missing information rather than guessing.
   ```

   The reply proposes a setup in a private chat. Saving creates the fleet; send it a message to start its first run.

3. Choose **… → Edit instructions** beside the chat title. Read the instructions, then open **Review and run options** to check the model, access, and budget.

   If the proposal needs changes, return to setup chat and describe them. Check the updated proposal before continuing.

4. Close the editor and choose **Save fleet**. The saved fleet opens in **Chat**.
5. Send your first task:

   ```text
   The signup page is ready for review.
   The welcome email still needs copy from Maya.
   Tomorrow, review signup and finish the email.
   ```

   The fleet replies in the conversation. Its wording varies by model.

## Verify it works

Check that the reply separates progress, blockers, and next actions without inventing facts.
Send a follow-up asking for a shorter version.

You can return to the saved fleet from the sidebar. **Activity** shows its runs and costs.

If no model is available, ask the workspace owner to check [model settings](/fleets/model-providers).
If saving or a run fails, follow the displayed next step or open [Troubleshooting](/fleets/troubleshooting).
Check a failed run before retrying; another run can incur another charge.

## What you learned

You described a task, checked its setup, saved a fleet, and reviewed its reply.
